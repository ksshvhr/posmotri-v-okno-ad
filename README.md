# Посмотри в окно

Учебный проект Яндекс Практикума: поиск и просмотр видеозаписей городских окон.

## Запуск

Откройте файл index.html в браузере. Список видео и поиск используют API проекта.

## Технологии

- HTML
- CSS (Flexbox)
- JavaScript

Проект создан на основе стартового репозитория Яндекс Практикума.
